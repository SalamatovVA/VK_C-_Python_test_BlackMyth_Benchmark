Так-как Black Myth: Wukong Benchmark Tool результаты проверок не сохраняются с открытым доступом, а так-же не отдаёт данные о текущей сцене, были приняты следующие решения:
    1. Для запуска теста эмулируются клики по экрану приложения, с фиксированными таймерами
    2. Результаты тестов выводятся в виде скриншотов

Для запуска приложения откройте папку publish и запустите b1_CPU_GPU_tester.exe и дождитесь вывода результатов
